# 論文通りの ABM 実装

**既存の再実装が論文のモデルでないことが分かったので、原論文から起こし直したもの。**

## なぜ作り直したか

`financial-abm-lab` の `abm_models/` にある実装を論文と突き合わせたところ：

- **Franke-Westerhoff** — 切り替え指数に herding 項も misalignment の2乗も無く、
  価格も対数ではなく水準で更新していた。パラメータ名だけが一致していて
  方程式が違う。**公表推定値（MSM で株価指数に当てたもの）は移植できない。**
- **Chiarella-Iori** — **板が存在しない。**best_bid/ask と depth がスカラー4つで、
  集約需要に線形の価格インパクトを掛けているだけ。指値もキューもマッチングも無い。
- Lux-Marchesi と Cont-Bouchaud は忠実だった（前者は論文の Hill α 1.92 対 1.93 を再現）。

**パラメータ名の一致は実装の一致を意味しない。**

## franke_westerhoff.py

Franke & Westerhoff (2009) BERG working paper の TPA 版。式(1)〜(8)、Table 1 の
パラメータをそのまま既定値にしてある。`verify()` が Table 2 と照合する。

実装中に **論文の印字と導出の食い違い**を1つ見つけた。式(5)の分母 `/2` を
外した版が Table 2 を再現する（V 0.711 対 0.70、Hill 3.60 対 3.57）。
経緯はソース中のコメントに書いた。

## chiarella_iori.py

Chiarella, Iori & Perelló (arXiv:0711.3581) の連続ダブルオークション。
期待形成・CARA 需要・注文配置表・指値キュー・マッチング・期限切れまで実装済み。
保存則（株式・現金）は成立している。

**論文の数値では論文の図が出ない。**注文の抽選区間の対数幅は
`ln(p_M/p_m) = αᵢ·Vᵢ·(p_m·Sᵢ + Cᵢ)` という恒等式（実測で比 1.0000）で、
「リスク回避度 × 分散 × 資産額」ちょうど。だから板の締まり具合は
**A = α·N_S·pᶠ** という群だけで決まり、Vᵢ が上がると板が開き、板が開くと
価格が跳ねて Vᵢ が上がる、という帰還ループができる。論文値 α=0.1 では
A=1500 で利得 2.05 > 1、つまり**論文自身のパラメータでは Figure 7 が出ない。**

再現には2つ決める必要があった。

1. **ノイズを √τᵢ で積む**（`noise_horizon`）。式(1) の ε を1ステップの率と
   読むと式(3) が τᵢ 倍するので、σ_ε=1e-4 が τᵢ/Σg≈115 倍されて 1.15% になり、
   V の床が σ_f² の 130倍になる。√τᵢ で積むと床は 8.5e-7 と σ_f² を下回る。
2. **A を下げる。**A=450 で利得 0.96、価格がファンダの 0.964、指値が中値の
   0.15%。**期待形成・CARA 需要・注文配置表・マッチングは正しかった。**

## S&P500 較正（`calibration/calibrate_cip.py`）

論文の数値が使えないので S&P500 直近1000営業日に合わせた。**論文パラメータは
「価格がファンダに追随する」制約で棄却される**（loss=inf）。較正後 loss=0.223、
A=50、σ₁=15.8、σ₂=6.77、τ=274。この点は板も価格も論文通りになる
（指値の距離が中央値 0.68%、99.1% が Figure 7 の軸内、価格 0.941）。

**制約を外すと loss は 0.063 まで下がるが、板が壊れる**（σ₂→9.86、価格が
ファンダの 0.313、指値の距離 41%）。**リターンの定型的事実に合わせることと
板を正気に保つことは逆方向に引き、しかもリターンの統計量だけ見ていても
この破綻は見えない。**

**どう較正しても直らないのが leverage**（z=5.18、符号ごと逆）。これは
`separation.py` で識別力が最大（garch_norm に 0.966）かつ ABM 論文が
ほとんど報告しない統計量である。

## 残っている食い違い

- **資力不足による注文削除。**発注済み指値の持ち主が現金／在庫を失ったときの
  扱いを論文は規定していない。板から消しているが、これが**注文が消える経路の
  65.7%** を占める。発注時に拘束する（エスクロー）読み方もある。
- **3パネルの順序。**論文は ファンダ < ノイズ < チャート、本実装は
  ノイズ < ファンダ < チャート。

## 副産物

- 論文に数値の無い τ_f は **τ_f = τᵢ** が正しい（定数 200 だと利得が 7e5）。
- **Figure 6 は成行注文サイズの図**で、距離の図は Figure 7。
- Vᵢ の次元は論文が付録 A で自分で決着させている（1ステップの履歴分散を
  意図的に horizon の代用にしている）。`v_horizon=False` が論文通り。
- **板の薄さと注文の寿命は原因ではない。**tau_cap を 2000→60000 にしても
  板の厚みも実現分散も動かない（板は寿命ではなく成行の消費で決まる）。
- r̂ と p̂ のクリップは全設定で一度も発動しない（0.00%）。無害。

```bash
python3 models/book_stats.py             # 板の統計量（約40秒）
python3 calibration/calibrate_cip.py     # S&P500 較正（約14分）
```
