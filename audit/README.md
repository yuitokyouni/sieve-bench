# 文献監査のコーディング表

**最上段の主張の根拠データ。**これが非公開だと、コードと表は再現可能なのに
一番強い主張だけが検証不能という一番まずい形になる。

| ファイル | 内容 |
|---|---|
| `relabeled.json` | 430本の論文それぞれについて、本文取得の可否・旧ラベル（要旨ベース）・本文中のカテゴリ出現回数 |
| `coding.py` | それを作ったスクリプト。正規表現と組み入れ基準がそのまま書いてある |

## 手続き

1. `financial-abm-lab` の 430本コーパス（arXiv ID つき）を入力にする
2. arXiv HTML → LaTeX ソースの順に本文を取得（**321本成功、109本失敗**）
3. **参考文献欄を除去する。**これをしないと `\bibitem{bouchaud2001leverage}` の
   ような引用を「本文で leverage を扱っている」と誤検出する
4. 9カテゴリの正規表現で出現回数を数える
5. 組み入れ基準：本文に "stylized fact" を含み、かつ市場シミュレーションであること
   → **54本**

## 既知の弱点

- **109本の本文が取れていない。**Semantic Scholar / Crossref のフォールバックは未実装
- **正規表現は「言及」を数えるのであって「報告」ではない。**序論や関連研究での
  言及も拾う。しきい値1回以上／3回以上の両方を出して感度を見ている
- **しきい値で順位が入れ替わる。**1回以上なら vol-clustering が首位（59.3%）、
  3回以上なら fat-tails（42.6%）。`leverage` だけは 9.3〜11.1% で動かない
- n=54 は小さい
